# Carrom Aim Assistant v1.1

Practice-oriented floating overlay.

### Added
- Manual draggable striker marker.
- Adjustable angle and power.
- Up to 3 cushion reflections.
- Optional 10x10 board grid.
- Reset control.
- Cleaner floating control panel.
- No automated taps, accessibility injection, game-memory modification, or auto-play.

Open in Android Studio and build the app module.
